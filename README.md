# 🃏 Memorama

Juego de memoria desarrollado con React y Vite.

## Cómo ejecutarlo

```bash
git clone https://github.com/LuisAc3ved4/Memorama.git
cd Memorama
npm install
npm run dev
```

React · Vite · JavaScript · CSS
